# Workflow Summary

Quick start for contributors:

1. Read docs/ENGINEERING_WORKFLOW.md and AGENTS.md.
2. Create a branch: feature/..., fix/..., or chore/...
3. Make the smallest useful change. Add tests and docs.
4. Run local validation (no build tool detected for this repo).
5. Open a PR using the provided template and complete the Quality Gate checklist.
6. Address review feedback. Do not merge until CI and reviews pass.

Core principle: The agent may create. The tools must verify.
