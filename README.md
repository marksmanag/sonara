# Sonara

Sonara — Hear Beyond. An intelligent music platform built in Africa for the world.

This repository is the canonical engineering foundation for Sonara. It contains the Sonara Constitution (governance, architecture, and development specification) and the repository documentation that define Phase 1: establishing a disciplined, documented, and research-driven foundation before major implementation.

Quick links

- Constitution: docs/constitution/README.md
- Decisions: docs/decisions/
- Contribution guide: CONTRIBUTING.md
- Security and vulnerability reporting: SECURITY.md

Phase 1 goal

Make the Sonara repository a clean, understandable, researched, documented, secure, testable, and extensible foundation from which the actual platform can be built. See docs/constitution/README.md for the Master Architecture & Development Specification.

Contributing

Please read CONTRIBUTING.md before opening issues or pull requests. All significant implementation must follow the Development Order and be preceded by appropriate documentation and ADRs.
