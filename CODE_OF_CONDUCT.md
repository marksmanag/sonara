# Code of Conduct

We expect all contributors and participants to follow professional, courteous, and inclusive behaviour. This document provides a short code of conduct for repository interactions.

Be respectful

- Treat everyone with respect and consideration.
- Assume good intentions.

Be collaborative

- Provide constructive feedback.
- Seek to clarify rather than to blame.

Unacceptable behaviour

- Harassment, hate speech, or discriminatory language.
- Personal attacks or threats.

Reporting

If you experience or witness conduct that violates this Code of Conduct, contact the maintainers or open an issue marked for private attention.

For a fuller policy, consider adopting the Contributor Covenant (https://www.contributor-covenant.org/).
